# Plant Experiments Tracker

React + Vite + TypeScript + Tailwind v4 (Material Design 3) + Supabase.
Android packaging via Capacitor.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Environment variables live in `.env.local` (git-ignored): `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`.
